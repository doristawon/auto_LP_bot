# Fables Points 對帳方法

本文件整理如何比對 Fables 官方 Points 結算與本機估值。文件不保存特定錢包、鏈上交易、部位、帳務數字或查詢時間線。

## 對帳步驟

1. 以官方 Points API 的已結算分數、推薦分數、已結算費用與已結算存入額作為官方基準，記錄其 distribution boundary。
2. 對齊本機事件簿與官方結算區間，檢查 LP 建倉、撤倉、再平衡、費用累計與 baseline 時間。
3. 區分即時／lifetime fees 與官方已結算費用；兩者時間範圍不同，不能直接相減或套用比例。
4. 只有在取得該日個人有效費用與全市場有效費用分母後，才可重算 fee-share points。缺少任一項時，推算只能作合理性檢查，不能視為官方結算結果。
5. 檢查 campaign day 邊界、週預算與 denominator coverage 是否與官方規則一致。若 coverage 不完整，應標記不確定性並避免顯示精確預測。

## 常見資料缺口

- 鏈上 `owed` 可能不是即時更新值；沒有觀察到累計事件不代表該期間沒有費用。
- 共用 hook 或跨池事件無法安全歸屬時，不應拿單一池資料推估個人或全市場費用。
- 本機日界線、官方結算時間或預算設定若不同，結果不可直接比較。
- 費用估值幣價、索引器 coverage 與官方結算快照可能使用不同時間點。

## 報告原則

- 明確標示官方已結算值、本機估值與未結算推估。
- 保留資料來源、時間邊界及 coverage 狀態，但公開文件使用合成或彙總資料。
- 不將無法獨立驗證的倍率、暫估分數或部分事件記錄描述成官方公式或承諾。
