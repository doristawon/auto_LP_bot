# 停損、停止清倉與分數校正

## 停損基準

- 中控台「總覽 → 停損與停止清倉」可設定啟用與虧損百分比，預設門檻 15%。
- 可選「LP 投入後起算」或原有「啟用時估值」。LP 模式在確認 LP 後的第一份完整資產快照保存錢包＋LP 估值與區塊；啟用時沒有 LP 就等待投入確認。有現存 LP 時，明確啟用／重設使用最新已確認快照，不回推缺乏完整估值的歷史成交。
- 同一輪 LP 模式跨撤池、換幣、再投入、換池及重啟持續累計；range ID 改變不重設停損基準。只有明確重設、切換起算方式或重新啟用停損才建立新一輪基準。
- 單純修改百分比不會重設基準。設定與基準保存於本機該錢包 state，重啟繼續使用。
- 虧損比例＝（基準估值－目前估值）／基準估值；估值包含已追蹤錢包資產、LP 本體及待領 LP 費用。
- 只有基準及目前外部轉帳對帳都完整時，才自動調整外部淨轉入。對帳未完整時固定採用啟用估值，並提示轉入／轉出後需手動重設基準。這不是原始投入本金的歷史損益。
- 未知價格、缺失估值、跨錢包快照或過期快照不會當成零資產觸發清倉；估值不可用時停止新交易。
- 停損在自動交易啟動後，沿用每次錢包監控掃描檢查；預設 5 分鐘。它不保證正好以門檻價格成交。唯讀掃描及暫停狀態不會啟動清倉。

## 暫停與停止清倉

「暫停自動平衡」保留 LP，禁止後續新交易。

「停止並撤池換成 USDG」需使用者確認，立刻暫停新交易，等待既有流程結束，再從最新鏈上狀態：

1. 檢查所有已辨識的 Fables LP，包含區間內部位；池子或 range key 不能完整確認時停止處理。
2. 逐一直接撤池並領費，使用精確 Q96 提領下限及交易前模擬；receipt 確認後再讀取 shares。
3. 依可驗證路徑把已辨識非 USDG 代幣換回 USDG，先報價、授權後重新報價、模擬並核對到帳。
4. 最後把超過 Gas 預留額的 ETH 換回 USDG。ETH 原生路徑帶入精確 msg.value，並附加 Sweep 退回未消耗 ETH。
5. 預設最大報價成本 5%，不取消最低到帳保護。無路徑、過高成本或沒有完整消耗的資產列為剩餘；部分清倉不能顯示為全部成功。

每個錢包獨立保存清倉 journal，與其他交易共用寫入佇列。交易結果不明時鎖住後續交易；重啟只做 receipt／nonce 對帳，不重複送出清倉單。已確認的中斷流程可由使用者重試剩餘資產。清倉後不會自動重新投入，必須先核對結果、重設停損基準再啟動。

## 分數估算

官方已結算 LP 分與推薦分分開保留。多日校正使用已完成且可核對的官方結算日，排除負修正、缺少累計費用 checkpoint、監控期間中途開始及已知紀錄缺口，至少兩個可用日才建立校正。

不同週的每日分數預算需先正規化；以費用加權擬合，保留本機 fee.accrual 與官方費用 delta 的差異。逐日留一交叉驗證用於顯示歷史誤差，不代表保證未來給分，也不是按時間先後的前向回測。全市場費用分母未完整時，畫面仍標為暫估，官方結算值具有優先權。另顯示「已記錄費用暫估」：紀錄不完整時只計入已記錄部分，不把歷史漏記比例作為放大倍數，也不覆寫官方總分。
